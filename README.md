# EduMaktab — Modern IT Education Platform

EduMaktab is a modern IT education platform in Uzbekistan offering professional courses in Frontend, Backend, Data Science, and Mobile development. With expert mentors and real projects, we help students build strong portfolios and launch successful tech careers.

## 🚀 Features

* **Course Catalog:** Detailed information on durations, lesson counts, and pricing for top tech courses.
* **Pricing Plans:** Standard, Professional, and Premium subscription tiers.
* **Expert Mentors:** Learn directly from industry professionals with years of experience.
* **Quick Registration:** Clean and interactive forms for seamless student enrollment.
* **Responsive UI:** Fully optimized design for desktop, tablet, and mobile screens.

## 🛠 Built With

* **HTML5 / CSS3 / JavaScript**
* **Responsive Design Principles**
